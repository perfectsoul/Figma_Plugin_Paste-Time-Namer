Paste Time Namer

Figma에 붙여넣은 이미지 레이어의 이름을 붙여넣기 시각으로 자동 변경하는 팀용 로컬 플러그인입니다.

이름 형식
YYYY-MM-DD HH.mm.ss.SSS-N — 예: 2026-10-15 15.42.09.137-1

1. 설치 전 준비

  • Figma Desktop 앱이 필요합니다. 브라우저 버전에서는 로컬 개발 플러그인을 처음 등록할 수 없습니다.
  • 전달받은 ZIP 파일을 원하는 고정 위치에 압축 해제합니다.

2. 설치 방법

  1. Figma Desktop을 실행하고 디자인 파일을 엽니다.
  2. Figma 메뉴에서 Plugins → Development → Import plugin from manifest…를 선택합니다.
  3. 압축을 푼 폴더 안의 manifest.json을 선택합니다.
  4. 플러그인 목록에 Paste Time Namer가 표시되면 설치가 완료된 것입니다.
중요: 설치 후 플러그인 폴더를 이동하거나 삭제하면 Figma가 실행 파일을 찾지 못합니다. 폴더 위치를 바꿨다면 기존 개발 플러그인을 제거한 뒤 다시 가져오세요.

3. 사용 방법

  1. 디자인 파일에서 Plugins → Development → Paste Time Namer를 실행합니다.
  2. 플러그인 창에 “이미지 붙여넣기를 감시하고 있습니다”가 표시되는지 확인합니다.
  3. 클립보드의 이미지를 Figma 캔버스 또는 기존 레이어에 붙여넣습니다.
  4. 새 이미지 레이어 또는 이미지 Fill이 변경된 레이어의 이름이 붙여넣기 시각으로 자동 변경됩니다.
  • 자동 변경 중지: 자동 이름 변경을 일시 중지합니다.
  • 자동 변경 시작: 중지한 자동 이름 변경을 다시 시작합니다.
  • 선택 항목 지금 명명: 선택한 이미지 레이어를 현재 시각으로 즉시 명명합니다.

4. 동작 범위와 주의사항

  • 외부 이미지 붙여넣기에는 자동 변경을 켜고, Figma 내부 복사·복제·이미지 가져오기 전에는 자동 변경 중지를 누릅니다. 작업 후 자동 변경 시작을 누르면 감시를 다시 시작하며, 중지 중에 만든 레이어를 소급해서 명명하지 않습니다.
  • 플러그인 창을 열어 둔 동안에만 자동 변경이 동작합니다.
  • 일반 도형이나 텍스트처럼 이미지 Fill이 없는 레이어는 변경하지 않습니다.
  • 밀리초 뒤에 일련번호를 붙여 같은 시각의 이름을 구분하고, 실행 시 확인한 기존 이름과 충돌하는 번호는 건너뜁니다.
  • 외부 서버나 인터넷으로 이미지 또는 문서 데이터를 전송하지 않습니다.

5. 문제 해결

  • 플러그인이 목록에 없음: Figma Desktop에서 manifest.json을 다시 가져옵니다.
  • 자동 변경이 안 됨: 플러그인 창이 열려 있고 “감시하고 있습니다” 상태인지 확인합니다.
  • 파일을 찾을 수 없다는 오류: 배포 폴더가 이동 또는 삭제되었는지 확인한 후 다시 가져옵니다.
  • 기존 이름으로 되돌리기: 이름 변경 직후 Figma의 Undo(Ctrl+Z 또는 ⌘Z)를 사용합니다.
